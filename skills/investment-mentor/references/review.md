# 每次交付前复核

复核范围与当前任务匹配，简版也检查关键数字和重大限制，不强制另一个Agent或指定工具。财务计算可用工具时实际复算；同一模型重复说“已检查”不是外部核验。

| 项目 | 实际检查 |
|---|---|
| 来源 | 数字/页码/日期/主体能否定位；主张/预测/事实分开；限定词、上下限、显示精度保留 |
| 算术 | 原数、单位、期间、变量及时点、合计/调节；区间上下端点分别复算，不能只核中点；费用、稀释及回报要求未重复计算 |
| 判断 | 证据能否支持标题和结论；未知未变成否定；不同配置未直接定矛盾；替代解释及主要反方未遗漏 |
| 停止 | 是否承认缺参后仍报估值、跑道、概率或准入数字；支持不足则删除/改为变量，并给恢复条件 |
| 跨轮 | 原判断准确回填；旧错明确撤回；反事实未写回现实；更新直接及有依据的连带项 |
| 任务 | 回答实际问题、遵守所选深度与研究范围；摘要继承正文条件及数值含义（如MOIC小于1不写保本）；未虚构工具/访谈/审计/审批 |

核对本轮是否按默认联网执行：若未外查，应有用户离线指令、任务不需外查或真实能力限制；不把摘要/记忆写成正文核验。影响判断的不确定项是否已具体询问，未回答是否仍暂停依赖项；已明确的条件不重复追问。

摘要、正文、风险、行动和追问中的证据状态一致。对“已核实/已到账/量产/矛盾/否决”及新增数字回指证据与参数；正文到账未知不能在风险表写已到账，人物履历不能在摘要变成公司技术资产已核实。纠错后额外检查本轮新数字、身份及门槛，防止撤回旧错又补新参数。

发现错误时修正并同步更改依赖结论，再核对相关部分；若仍缺资料，保留限制并暂停受影响判断，独立部分正常交付。完成后停止，不无限补写或自评循环。

仅保留可检查的来源摘要、假设、算式、结果、修正/撤回及未完成检查，不要求内部思维过程。正式报告按[输出要求](output.md)保留相应附录和实际完成范围；不输出冗长逐步自评。技术日志仅测试/审计时展开。不得在未执行检查时声称“通过”，复核不等于企业事实经独立验证。

## 结构与人读复查

按所选任务/档位核对三层、标题顺序、六个简报字段、正文和附录必备项；详细/全面版完整项目检查9视角、12维及五层验证实际状态。必备项不能静默省略，补齐相关缺项后再交付；事实不足则写四项缺口，不伪造内容或循环补写。

读一遍摘要与关键正文：主语/对象是否明确，句子是否完整，术语是否解释，依据为何改变判断是否说清，转折是否真实，数值口径和限制是否相邻。段落要连贯，表格不能替代全部分析。同一信息重复则用短结论和证据ID回指，保留原数及条件。自动标题/行数检查不代表事实、逻辑或语言质量通过。

## ESG实质复核

完整项目逐项核E/S/G、主体与实际活动、规则性质和现行时点、负面归属、证据与风险分离、整改实际执行、具体追问、财务无重复和效益/企业现金/股东回报区分。第9节与摘要、风险、估值、问题及附录状态一致；简版保留ESG子节。环境未知不写低风险，绿色机会不抵销严重负面；机械子标题通过不等于实质合格。
