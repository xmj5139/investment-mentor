# 项目初筛

正式报告的目录与必填项统一遵守[输出要求](output.md)，本模块只规定分析内容；专项任务采用相应固定目录，用户指定模板按其要求映射。

从用户关心的决策开始：是否继续看、进入哪类尽调、是否具备谈判基础。区分公司股权和单项工程/资产，不将项目收入直接当作公司可归属利润。

## 工作内容

1. 识别主体、产品、客户、商业模式、资金用途、拟议交易和材料期间。缺失融资额不妨碍分析需求真实性，但缺失主体会阻断主体与股权结论。
2. 用CD扫描相关维度。完整BP初筛覆盖12维，重点看需求、交付、收入质量、现金、权属和资本接续；适用阶段有差异，不以成熟期利润要求否定所有早期研发项目。
3. DP验证最影响跟进动作的价值点，明确反方解释。例如收入增长是否仅来自一次性项目、关联交易、降价或宽信用。
4. 评估能否通过低成本补证改变判断。否决风险已证实时给停止条件；仅有线索时给核验安排，避免直接定性违法或造假。
5. CI按条件触发，不以非共识故事替代商业和技术证据。

## 行业证据路径

- 制造业/装备：样品/试验—中试—客户认证—采购订单—生产交付—验收—回款；分别记录状态及主体。规划产能、安装产能、合格产能、可售产量不能混用，订单需看取消条件、履约义务和回款。
- 软件/SaaS：签约—付费—实际部署/使用—留存/续费/扩张—毛利—现金回收；区分试用、免费、付费及关联账户，统一MRR/ARR、流失和队列口径。
- 项目制服务：中标—合同—实施—验收—结算—回款，检查客户预算、跨期确认、预付款及人员产能；不要求强行改成订阅模式。
- 医疗及其他受监管研发：科学/技术验证、许可与临床/注册、商业准入、支付及交付分开；当前适用的注册与监管规则需核验。

硬件、研发服务和许可收入并存时分业务走证据路径；单笔一次性服务不自动证明全部收入不可持续。优先安排少量能改变动作且可执行的补证，不以所有资料齐全作为接触条件。涉及现金、预测或收益时读取[财务模块](finance.md)。

## 输出

结论限定到“基于所给材料的初步跟进建议”。给关键价值与证据、最可能推翻判断的风险、优先补证及行动。资料清单写成“要什么—验证什么—何种结果继续/停止”，不堆全套尽调目录。没有证据证明时不把“订单增长”“已量产”“确定上市”写成事实。

涉及完整项目或相关重要事项时按[ESG模块](esg.md)识别E/S/G及行业要求；适用性未知先具体询问。与既有风险、财务和主体核查共享证据，按[统一输出](output.md)呈现，不另造目录或重复成本。
