# ESG情况与投资影响

完整项目分析读取本模块，按实际经营活动选择行业引用。ESG是投资研究的一部分，需同时观察对企业前景/回报的影响，以及企业和重要价值链活动对环境、人员与社会的影响。后者即使尚未量化成损失，也记录严重程度、范围、可补救性与受影响群体。

## 适用范围与行业选择

先锚定拟投主体、子公司及主要场所，识别产品/工艺、研发/建设/生产/销售阶段、地区、自营/外包和重要价值链。选择主行业，有实际交叉活动时追加模块；不按融资轮次或公司宣传标签代替经营识别。决定性信息不明，列不同解释并具体询问，只暂停相关判断。

| 实际业务 | 读取 |
|---|---|
| 芯片设计/IP、晶圆/封测、电子制造 | [半导体与电子](esg-semi.md) |
| 装备研发制造/安装、新材料/化工/回收 | [装备与新材料](esg-materials.md) |
| 能源储能设备、能源资产、环保运营 | [能源与环保](esg-energy.md) |
| 软件/SaaS/数据、模型与生成式AI | [软件与人工智能](esg-software.md) |
| 医疗器械/诊断/医疗软件、药物/临床服务 | [医疗健康](esg-health.md) |

其他行业使用本模块的E/S/G通用筛查，按实际活动核查相应规则，明确行业专项覆盖限制，不能声称已完成未加载的行业标准审查。[标准来源与读取边界](esg-sources.md)提供入口，项目使用时核现行版本与适用性。采用何种标准、适用到哪项命题要写清，不能泛称“全面符合国际ESG标准”。

## 通用筛查与标准性质

E：适用的许可、污染/废弃物、能源水资源、气候灾害与产品环境主张。S：劳动用工、职业健康安全、产品/客户责任、数据隐私、供应链和重要社区影响。G：控制及授权、关联交易/资金占用、诚信反腐、信息与内控、举报及少数股东保护。初筛识别重要风险与补证；尽调/交割条件判断需要相应执行证据，不要求初筛前完成全部专项审计。

规则分四类：法律监管/许可及依法适用的技术要求；已核对的有效合同和客户要求；披露/管理参考框架；可比基准和投资改进建议。按主体、地区、活动、阶段核对性质及效力，推荐性标准不能因名称自动成为法定义务，被法律或合同纳入时核其具体依据。没有额外基金制度就不创造机构负面清单。

标准记录至少包含名称/编号、发布主体、版本及生效/过渡安排、性质、适用地区/活动、相关条款与原文位置、核验日、支持范围和未核事项。技术限值另记产品/污染物/排口、工况、方法、单位及可比条件；关系不明保留各要求并询问/转专项核查，不自行裁定效力优先级。标准链接存在不等于已读全文，也不等于仍然有效。

## 证据、风险与行动

默认按[证据规则](evidence.md)实际核查重要公开命题，先读材料；仅材料/离线及宿主能力边界优先。核名称/信用代码、历史名、场所、期间及筛选范围；正文读不到保持未核，未查到记录不等于不存在。公开检索只传必要公开线索，不上传未公开员工、客户和完整BP。

关键事项分开记录：适用性（适用/不适用/待确认及原因）、命题分类/EL及实际核验、具体影响、管理响应、建议动作。风险与证据状态分开，不因资料少自动评低/高风险。充分支持时可用高/中/低并解释，高风险关注重大伤害、经营中断或回报侵蚀及控制不足；中风险为实质缺陷和整改不确定；低风险仅限已充分支持的所述范围。不足写“暂不能评级”，不设统一百分制、跨行业排名或无来源门槛。不用低概率忽略严重/广泛/难补救影响，无依据不赋概率。

“未查到处罚”“有制度”“有认证”“园区代处理”均不能独立证明持续合规。核证书的持有人、场所、范围、有效期与状态，再核实际运行。创始人持股集中不自动说明治理失效，不机械套用上市公司独董比例。治理记录与既有法务/财务模块共享证据，不重复列金额。

整改分企业主张、取得材料、实际核对、复查及剩余责任；缴罚款或提交方案不代表解除风险。负面报道、同名企业或不同期间的记录要先对齐，不直接定违法/否决；已核实重大不利事项也不能被绿色业务、捐赠或其他正面贡献抵销。

## 财务、价值与交易

重要事项说明对客户准入、生产/研发、费用、现金、融资和退出的传导。成本有依据才量化，记录付款主体、时点、一次性/持续性、税费、营运资金、保险/追偿及是否已入模型。增量自由现金流＝增量经营现金流－增量资本开支；会计费用不直接等于现金，不把已计入的整改再扣一次，不自动增加折现率或给ESG溢价。缺金额/时间/责任则给变量与问题，暂停相关数值。

环境/社会效益与企业现金流、股东回报分开。节能主张核相同功能、质量、工况和系统边界，实验室效率不能外推全部客户或全年；能耗/水耗强度要有同边界分母，不能无解释横比不同产品。温室气体核算需组织/运营边界、气体、期间、活动数据、因子来源/版本和单位，缺数据不填0或称盘查完成。企业排放与产品避免排放不相抵，减排潜力、权利/登记/签发、交易及到账逐步核实。客户节约不自动变成本公司收入，ESG标签不自动触发CI。

建议分别列投资前解决、可投后整改和持续跟进事项，给责任角色、证据/验收条件及建议时间；未知时点不猜。交易保护、信息权、赔偿和里程碑标“建议”，已签条款与可执行性、对方支付能力分别核。将违法损失计入模型不代表可以继续相关行为。

## 询问、输出与复核

会改变结论的主体/活动、产品用途与许可、负面归属、整改、成本或规则冲突不明，必须向用户提出具体问题，写所需资料、影响和恢复条件；已有明确材料不重复问，未答不视作确认。只暂停相应合规/价格/交割结论，有依据的独立分析继续，列缺口后停止补写。

正式结构见[输出要求](output.md)：详细/全面完整项目第9节固定六个子节；简版第4节保留独立ESG子节，E/S/G均有当前状态或具体缺口。专项只展开相关事项；短问直接答，不强制全报告。每个重要事项写“适用依据—当前证据及边界—具体影响—缺口/动作”，表格配完整中文分析。无异常限定实际检查范围，不能写“全部合规”。

输出前实际检查行业/活动匹配、规则时点性质、E/S/G覆盖、证据与风险分离、具体询问、整改状态、财务不重复、效益与收益分开、跨层条件一致和人读语言。目录检查不能证明事实、现场合规或语言质量。

资料缺失本身列为待核事项或暂停条件，不命名为“疑似否决项”；有具体不利事件线索时描述事件与尚待确认部分，否决还须有实际适用依据及充分事实。积极材料与缺口不能用评分平均。
