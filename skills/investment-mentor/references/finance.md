# 财务公式、现金桥接与风险

先统一主体、合并范围、期间、币种、单位、适用准则及审计意见；历史实绩、预测和分析假设分列。资产=负债+权益，现金流与余额勾稽，异常差异保留原数和调节。不把简式利润冒充完整税前利润或审计结果。

收入按企业适用准则及合同履约、控制权转移或履约进度确认；合同、交付/验收、开票、确认收入、回款是不同命题。回款不构成所有收入确认的前提，未回款可形成应收或合同资产；已回款也可能是预收。证据链用于核查业务与现金，不是必须全走完才能确认收入的统一会计规则。

## 输入—计算—用途

输入先标来源/题设、历史/预测/假设、精确值/区间/上下界、单位期间及权益/现金口径。影响计算的不确定参数先按[询问与暂停](clarification.md)向用户确认；未答不填行业常见值。用户明确给定的合成情景可算，注明非现实核验。

计算复核与项目用途分别判断：算术成立不证明输入真实、交易有效或投资应通过。资金登记、认缴/实缴、投资价款、股权比例、老股/新增和银行现金分开；亿元级披露不能自行取精确1亿元。金额与同权增资结构未知时，优先给V=新增现金/新增权益比例及待核条件，不以任意点数形成项目估值锚。

明确结果是勾稽、教学情景、价格约束、独立估值还是已实现回报。重要上限用未舍入值判断，展示约数不向上取整放宽约束。假设缺口、参数未知和已证风险分别处理；“建议/保守/仅供参考”不能补足依据。

## 测算纪律

重要计算记录原数/来源位置、单位期间、公式、假设、结果及适用范围。计算工具可用时实际复算，任意适当计算器/代码/表格均可；[可选计算器](../scripts/calc.py)仅作确定性算术，不验证输入真实或完整性。无工具可展示简单算式，复杂模型暂缓，不虚构工具。公式存在不代表参数已知。

| 项目 | 公式与限制 |
|---|---|
| 同比/增长倍数 | 本期/上期−1；倍数=本期/上期。上期正数且期间可比；零/负基数改列绝对变动和解释，避免误导百分比 |
| CAGR | (期末/期初)^(1/n)−1，n为相隔年数；正基数、同口径；亏转盈不用普通CAGR |
| 毛利率/费用率 | (收入−营业成本)/收入；对应费用/收入，收入须有意义。费用化研发、资本化投入及现金付款分开 |
| 利润质量 | 原报表→逐项分析调整→归一化利润；净利润→非现金及营运资金等调节→经营现金流。调整注明理由、税及持续性影响，不冒充法定扣非或审计调整 |
| DSO | 平均对应应收/同期赊销收入×期间天数；含税、合同资产/票据范围一致。用总收入做代理须标近似 |
| DIO/DPO/CCC | 平均存货/营业成本×天数；平均贸易应付/对应采购额×天数；CCC=DSO+DIO−DPO。平均余额与期间匹配，采购额缺失不硬填，代理口径明示 |
| 偿债 | 流动资产/流动负债；负债/资产；另列计息债务、到期表、逾期、担保、回购及或有支付。分母有效，负权益/单个比率不替代现金偿债分析 |
| 分析FCF | 经营现金净流量−现金资本开支。定义资本开支、资本化研发及列报范围，已扣项目不再扣；该简式不自动等于DCF用FCFF |

百分数与百分点分开；区间传播到结果，中点须明确；大于号不能当精确值或上限。整数百分比可能经四舍五入，检查其误差范围。利润差不能仅凭方向一致归因利息/补贴，也不足以直接认定造假。核对完整预测底稿及遗漏科目。

## 现金与融资

用可动用现金口径按月/里程碑桥接：期初可用现金＋经营净现金流＋资本及其他投资净现金流＋融资净现金流＋适用其他调整＝期末可用现金。融资净额含偿债；其他调整包含实际适用的汇率/受限变化等且不重复计。报表现金等价物与模型可用现金的差异另调节。

列现金收付款节奏、资本开支、营运资金、已发生支出、最低运营余额、债务到期、融资到款与下一验证节点。未落实融资单列情景，不当确定现金。研发费用已经影响利润，不能与亏损相加；会计亏损也不等于月净消耗。拟投资金额不等于本轮全部融资或一次到账金额。

现金跑道=可用现金/月净现金消耗，仅在消耗为正且稳定、无重大集中支付等简化条件下作静态指标，需列假设。其他情况用滚动现金预算。缺期初现金和收支桥接时，不能认定资金充足/不足，也不能从融资÷年度费用/亏损给跑道、上限、月份区间或概率。可保留纯金额比较，但不能据它改变资金充分性结论。

已识别资金缺口=满足给定最低现金要求所需的新增确定资金，按预算最低点求；说明后续融资成本、稀释及失败后果。支持下一里程碑与支持持续扩张是不同判断。

## 风险与情景

风险按“信号—证据—替代原因—财务影响—补证/触发—动作”写，不给所有行业一条阈值。重点核查：

- 合同/履约/收入/发票/回款及退货回购；收入与现金偏离是否由账期、增长或异常确认造成。
- 应收/合同资产逾期、期后回款；库存账龄、跌价、良率与产能利用率；预付款、供应链及营运资金占用。
- 补贴、一次性收益、研发资本化、折旧摊销及会计归集对利润的影响；亏损研发企业也须看里程碑和资本效率，不能一律否定。
- 关联占款、担保、债务期限、回购/承诺及支付能力；真实公允关联交易和NRE不因标签自动否决。
- 量价、客户导入、毛利、费用、CapEx、周转与融资是否勾稽；收入预测须拆产品/服务和交付期间，全年均值不当月度事实。

按关键驱动设置基准/下行/上行情景，测试验收延期、回款放慢、毛利下降、融资延迟等；参数有依据才代数值，无概率依据不加权。说明哪些变化影响公司价值、现金、交易回报或机构适配，避免整体一律下调。风险信号、待核项与已证实问题分别列。

## 原始会计依据

实际使用先核对企业适用准则及期间。收入确认规则参考财政部收入准则修订解读，不能将本模块分析指标当作法定报表口径。

## ESG现金衔接

按[ESG模块](esg.md)核整改、停产、质保、安全、数据和退役等有据现金影响，先明确主体、时点、税费及是否已入模型。增量自由现金流＝增量经营现金流－增量资本开支；不重复扣减，不因ESG标签自动折价/溢价，缺参只保留变量与所需证据。客户节能及社会贡献不直接视为公司收入。

存量余额与期间费用分开：应付工资等期末负债余额差异，不能直接推出当期费用、利润或现金损失差异。先核期初、计提、支付、重分类及期末调节；原数和差额保留，缺桥接就暂停对应利润/现金/估值调整。不得把未知成本称为“已含”或“未含”某历史/预算口径。
