# 本版测试方法

用例库含52个继承案例及18个新增ESG案例。新增18项组成6组共享输入，覆盖五行业、简/详/全面、短问、证据冲突及财务。组内案例不能重复计作独立模型调用；本轮实际执行范围见TEST_REPORT，未跑用例保持未测。

被测Agent仅接收运行技能及本组任务，或完整独立提示词及同一任务，不接收rubric、作者样稿或其他模型答案。所有合成任务明确仅材料/离线；不由本轮得出联网能力结论。Codex文件模式读取指定入口与必要引用，外部CLI用独立文本隔离运行；两模式分别记录。

检查最终回答的事实/假设、归属、规则性质、具体问题、停止项、算式、摘要传播和人读语言。正式报告另用check_output.py查格式，标题通过不能抵销实质失败。风险判定错误、虚构工具、无据数值单列。外部原始最终回答和输入哈希单独交付，不把敏感运行配置放入技能包。复测只需本版规则和相同匿名任务，不依赖历史回答。

tests/fixtures内三档文件为作者格式示例，不是模型行为测试。scripts/test_output.py是检查器单元测试，calc_cases.json是算术测试；各类通过数分别统计。
