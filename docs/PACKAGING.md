# 发布内容与边界

此次发布整理以通用0.4.5候选版为源，2026-10-29增加仓库级说明和近期测试脱敏摘要。入口、引用模块与独立提示词的运行规则保持该版本；仅通用验证器移除了私有来源专用的哨兵名称，重新生成包校验清单。

`CHECKSUMS.json`记录仓库文件内容，`skills/investment-mentor/PACKAGE_MANIFEST.json`记录技能包内容。打包ZIP以本目录的显式文件清单为准，不将工作区整体提交；本地原有文件及私有测试包保持原状。

技能格式依据：[Agent Skills规范](https://agentskills.io/specification)，核对日期2026-10-29。平台实际发现、权限和工具能力因宿主而异，本次没有重新验证所有平台安装要求。
